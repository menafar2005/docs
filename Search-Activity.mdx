## جستجوی فعالیت

با این Endpoint می‌توانید فعالیت‌ها را براساس بازه زمانی، نوع فعالیت، مخاطب، مسئول، تگ، وضعیت انجام یا رکورد مرتبط پیدا کنید.‎ این درخواست برای ساخت لیست فعالیت‌ها، دریافت برنامه کاری کاربران یا پیدا‌کردن فعالیت‌های مرتبط با یک معامله یا کارت مناسب است.‎

```http
POST {{baseURL}}/api/activity/search?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## Header درخواست

```text
Content-Type: application/json
```

## بدنه درخواست

<ParamField path="FromDate" type="string">
  ابتدای بازه زمانی با قالب تاریخ و زمان مورد انتظار Endpoint.
</ParamField>

<ParamField path="ToDate" type="string">
  انتهای بازه زمانی با قالب تاریخ و زمان مورد انتظار Endpoint.
</ParamField>

<ParamField path="SortType" type="number">
  معیار یا روش مرتب‌سازی نتایج.
</ParamField>

<ParamField path="From" type="number">
  اندیس شروع نتایج برای صفحه‌بندی است. مثلا `0` یعنی دریافت از اولین نتیجه و `20` یعنی ۲۰ نتیجه اول رد شوند.
</ParamField>

<ParamField path="Limit" type="number">
  حداکثر تعداد رکوردی است که در همین پاسخ برگردانده می‌شود.
</ParamField>

<ParamField path="ActivityTypeIds[]" type="array">
  فهرست شناسه نوع‌های فعالیت است و نتایج را به همین نوع‌ها محدود می‌کند.

  <Expandable title="وابستگی‌ها">
    این فیلد باید `Id` یکی از نوع‌های فعالیت موجود در دیدار را بگیرد.

    - [Activity Type](/Activity-Type) — `Id` نوع فعالیت موردنظر را بردارید
  </Expandable>
</ParamField>

<ParamField path="ContactIds[]" type="array">
  فهرست شناسه اشخاص یا شرکت‌های مرتبط است.

  <Expandable title="وابستگی‌ها">
    هر مقدار باید `Id` یک شخص یا شرکت موجود در دیدار باشد.

    - [Create Person](/Create-Person) — ساخت شخص جدید
    - [Get Person By Mobile](/Get-Person-By-Mobile) — پیداکردن شخص با موبایل
    - [Search Person](/Search-Person) — جست‌وجوی شخص
    - [Create Company](/Create-Company) — ساخت شرکت جدید
    - [Search Company](/Search-Company) — جست‌وجوی شرکت
  </Expandable>
</ParamField>

<ParamField path="TagIds[]" type="array">
  فهرست شناسه تگ‌ها است و نتایج را به رکوردهای دارای این تگ‌ها محدود می‌کند.

  <Expandable title="وابستگی‌ها">
    این فیلد باید `Id` تگ موجود در دیدار را بگیرد.

    - [Tags](/Tags) — `Id` تگ موردنظر را بردارید
  </Expandable>
</ParamField>

<ParamField path="OwnerId" type="string">
  شناسه User مسئول رکورد است و نتایج یا مسئولیت رکورد براساس همین کاربر تعیین می‌شود.

  <Expandable title="وابستگی‌ها">
    این فیلد نام کاربر را نمی‌پذیرد؛ باید `UserId` یک User موجود در دیدار را بفرستید.

    - [User List](/User-List) — مقدار `UserId` کاربر موردنظر را بردارید
  </Expandable>
</ParamField>

<ParamField path="CreatorId" type="string">
  شناسه Userی است که به‌عنوان ایجادکننده رکورد ثبت می‌شود.

  <Expandable title="وابستگی‌ها">
    این فیلد نام کاربر را نمی‌پذیرد؛ باید `UserId` یک User موجود در دیدار را بفرستید.

    - [User List](/User-List) — مقدار `UserId` کاربر موردنظر را بردارید
  </Expandable>
</ParamField>

<ParamField path="IsDone" type="boolean">
  فیلتر یا وضعیت انجام‌شدن رکورد؛ مقدار آن تعیین می‌کند رکورد انجام‌شده محسوب شود یا خیر.

  <Expandable title="مقادیر مجاز">
    - `true` — فقط رکوردهای انجام‌شده
    - `false` — فقط رکوردهای انجام‌نشده
  </Expandable>
</ParamField>

<ParamField path="IsDeleted" type="boolean">
  مشخص می‌کند رکورد حذف شده است یا همچنان فعال است.

  <Expandable title="مقادیر مجاز">
    - `true` — فقط رکوردهای حذف‌شده
    - `false` — فقط رکوردهای حذف‌نشده
  </Expandable>
</ParamField>

<ParamField path="DealId" type="string">
  شناسه معامله‌ای است که فاکتور، پیش‌فاکتور یا فیلتر باید به آن مرتبط باشد.

  <Expandable title="وابستگی‌ها">
    مقدار این فیلد باید `Id` یک معامله موجود در دیدار باشد.

    - [Create Deal](/Create-Deal) — اگر معامله هنوز ساخته نشده است
    - [Get Deal By Id](/Get-Deal-By-Id) — اگر `Id` معامله را دارید
    - [Search Deal](/Search-Deal) — برای جست‌وجوی معامله
  </Expandable>
</ParamField>

<ParamField path="CaseId" type="string">
  شناسه کارت مرتبط است و نتایج یا رکورد را به همان کارت محدود یا متصل می‌کند.

  <Expandable title="وابستگی‌ها">
    مقدار این فیلد باید `Id` یک کارت موجود در دیدار باشد.

    - [Create Case](/Create-Case) — اگر کارت هنوز ساخته نشده است
    - [Search Case](/Search-Case) — برای جست‌وجوی کارت
  </Expandable>
</ParamField>
