# جستجوی محصولات

با این Endpoint می‌توانید محصولات دیدار را براساس عنوانشان جستجو کنید.‎ این درخواست زمانی کاربرد دارد که ID یا کد محصول را ندارید و می‌خواهید محصول موردنظر را از روی نام آن پیدا کنید.‎ با `From` و `Limit` نیز می‌توانید نتایج را صفحه‌بندی کنید.‎

```http
POST {{didar}}/api/product/search?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## Header درخواست

```text
Content-Type: application/json
```

## بدنه درخواست

<ParamField path="Criteria" type="object" required>
  معیارهای جستجوی محصول

  <Expandable title="property">
    <ParamField path="Criteria.Keywords" type="string" required>
      عبارتی است که جست‌وجو براساس آن انجام می‌شود. نتیجه فقط رکوردهایی را برمی‌گرداند که عنوان محصول با این عبارت تطبیق داشته باشد.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="From" type="number">
  اندیس شروع نتایج برای صفحه‌بندی است. مثلا `0` یعنی دریافت از اولین نتیجه و `20` یعنی ۲۰ نتیجه اول رد شوند.
</ParamField>

<ParamField path="Limit" type="number">
  حداکثر تعداد رکوردی است که در همین پاسخ برگردانده می‌شود.
</ParamField>

<RequestExample>

```json Request Body (JSON)
{
  "Criteria": {
    "Keywords": "تست"
  },
  "From": 0,
  "Limit": 10
}
```

```shellscript Request Body (cURL)
curl --location '{{didar}}/api/product/search?apikey={{API_KEY}}' \
--header 'Content-Type: application/json' \
--data '{
  "Criteria": {
    "Keywords": "اشتراک"
  },
  "From": 0,
  "Limit": 10
}'
```

</RequestExample>
