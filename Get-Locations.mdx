# دریافت لوکیشن ها (استان، شهر) — اطلاعات پایه

این Endpoint ساختار مکان‌های قابل استفاده در دیدار را شامل کشورها، استان‌ها و شهرها برمی‌گرداند.‎ از IDهای پاسخ برای مقداردهی `ProvinceId` و `CityId` هنگام ثبت یا ویرایش اشخاص و شرکت‌ها استفاده کنید.‎

```http
POST {{baseURL}}/api/shared/GetLocations
```

## Header درخواست

```text
content-type: application/json
```
