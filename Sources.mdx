# نحوه آشنایی — اطلاعات پایه

نحوه آشنایی مشخص می‌کند مشتری یا معامله از چه مسیری وارد فرایند فروش شده است؛ مثل سایت، تبلیغات یا معرفی.‎ این Endpoint فهرست گزینه‌های تعریف‌شده را برمی‌گرداند تا ID گزینه موردنظر را در `SourceId` معامله استفاده کنید.‎

```http
POST {{baseURL}}/api/Source/GetList?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |
