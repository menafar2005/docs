## جستجوی شخص

با این Endpoint می‌توانید اشخاص ثبت‌شده در دیدار را براساس نام، موبایل، تلفن، ایمیل، کد ملی، کد مشتری، تاریخ ثبت و چند فیلتر دیگر جستجو کنید.‎ نتایج صفحه‌بندی می‌شوند و برای پیدا‌کردن شخص زمانی مناسب‌اند که ID دقیق او را ندارید.‎

```http
POST https://app.didar.me/api/contact/PersonSearch?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## Header درخواست

```text
Content-Type: application/json
```

## بدنه درخواست

<ParamField path="Criteria" type="object" required>
  مجموعه معیارهای جست‌وجو و فیلتر؛ فقط رکوردهایی که با این شرایط سازگار باشند در نتیجه برگردانده می‌شوند.

  <Expandable title="property">
    <ParamField path="Criteria.IsDeleted" type="number">
      مشخص می‌کند رکورد حذف شده است یا همچنان فعال است. مقادیری که می توانید ارسال کنید: `0` → رکورد حذف نشده باشد `1` → حذف شده باشد
    </ParamField>

    <ParamField path="Criteria.IsPinned" type="number">
      فیلتر سنجاق‌شدن رکوردها. مقادیری که می توانید ارسال کنید: `-1` → سنجاق نشده باشد `1` → سنجاق شده باشد
    </ParamField>

    <ParamField path="Criteria.IsVIP" type="number">
      فیلتر مخاطبان ویژه. مقادیری که می توانید ارسال کنید: `-1` → شخص ویژه نباشد `1` → شخص ویژه باشد
    </ParamField>

    <ParamField path="Criteria.SortOrder" type="number">
      جهت مرتب‌سازی نتایج، مانند صعودی یا نزولی.
    </ParamField>

    <ParamField path="Criteria.Keywords" type="null">
      عبارتی است که جست‌وجو براساس آن انجام می‌شود. نتیجه فقط رکوردهایی را برمی‌گرداند که فیلد متنی مرتبط با این عبارت تطبیق داشته باشد.
    </ParamField>

    <ParamField path="Criteria.MobilePhone" type="string">
      شماره موبایل برای جست‌وجو یا محدودکردن نتایج مخاطبان.
    </ParamField>

    <ParamField path="Criteria.WorkPhone" type="string">
      شماره تلفن محل کار برای جست‌وجوی مخاطب.
    </ParamField>

    <ParamField path="Criteria.Email" type="string">
      نشانی ایمیل برای جست‌وجوی مخاطب.
    </ParamField>

    <ParamField path="Criteria.NationalCode" type="string">
      کد ملی برای جست‌وجوی شخص.
    </ParamField>

    <ParamField path="Criteria.ZipCode" type="string">
      کد پستی برای محدودکردن نتایج مخاطبان.
    </ParamField>

    <ParamField path="Criteria.CustomerCode" type="string">
      کد مشتری برای جست‌وجوی دقیق مخاطب.
    </ParamField>

    <ParamField path="Criteria.SearchFromTime" type="string">
      ابتدای بازه زمانی جست‌وجو؛ رکوردهای پیش از این زمان از نتیجه حذف می‌شوند.
    </ParamField>

    <ParamField path="Criteria.SearchToTime" type="string">
      انتهای بازه زمانی جست‌وجو؛ رکوردهای پس از این زمان از نتیجه حذف می‌شوند.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="From" type="number">
  اندیس شروع نتایج برای صفحه‌بندی است. مثلا `0` یعنی دریافت از اولین نتیجه و `20` یعنی ۲۰ نتیجه اول رد شوند.
</ParamField>

<ParamField path="Limit" type="number">
  حداکثر تعداد رکوردی است که در همین پاسخ برگردانده می‌شود.
</ParamField>
