## دریافت جزئیات شرکت توسط شناسه شرکت

با این Endpoint می‌توانید اطلاعات کامل یک شرکت مشخص را براساس ID آن دریافت کنید.‎ این درخواست زمانی مناسب است که شرکت را از قبل پیدا کرده‌اید و به اطلاعات ثبت‌شده، مسئول، راه‌های تماس، آدرس‌ها یا فیلدهای اضافه آن نیاز دارید.‎

```http
POST {{baseURL}}/api/contact/GetContactDetail?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## Header درخواست

```text
Content-Type: application/json
```

## بدنه درخواست

<ParamField path="Id" type="string" required>
  شناسه یکتای شرکتی است که می‌خواهید اطلاعاتش را دریافت کنید.
</ParamField>

<RequestExample>

```json Request Body (JSON)
{
  "Id": "5a0b0303-4b21-4144-9576-d5f1504c3573"
}
```

```shellscript Request Body (cURL)
curl --location --request POST '{{baseURL}}/api/contact/GetContactDetail?apikey={{API_KEY}}' \
--header 'Content-Type: application/json' \
--data '{
  "Id": "5a0b0303-4b21-4144-9576-d5f1504c3573"
}'
```

</RequestExample>
