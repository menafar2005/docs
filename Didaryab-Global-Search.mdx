## Didaryab — دیداریاب

دیداریاب برای جستجوی هم‌زمان در چند بخش مختلف دیدار ساخته شده است.‎ با ارسال یک عبارت و مشخص‌کردن نوع رکوردها، می‌توانید آن عبارت را میان اشخاص، شرکت‌ها، معاملات، کارت‌ها و فایل‌های پیوست‌شده جستجو کنید.‎

```http
POST {{baseURL}}/api/search/search?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## Header درخواست

```text
Content-Type: application/json
```

## بدنه درخواست

<ParamField path="Keyword" type="string">
  عبارتی است که دیداریاب باید در Entityهای انتخاب‌شده جست‌وجو کند؛ مثلا نام شخص، عنوان معامله یا بخشی از نام شرکت.
</ParamField>

<ParamField path="Types[]" type="array">
  مشخص می‌کند دیداریاب عبارت `Keyword` را داخل کدام نوع رکوردها جست‌وجو کند. می‌توانید یک یا چند نوع را هم‌زمان بفرستید.

  <Expandable title="مقادیر مجاز">
    - `contact` — جست‌وجو بین اشخاص
    - `company` — جست‌وجو بین شرکت‌ها
    - `deal` — جست‌وجو بین معامله‌ها
    - `case` — جست‌وجو بین کارت‌ها
    - `attachment` — جست‌وجو بین فایل‌های پیوست‌شده
  </Expandable>
</ParamField>

<RequestExample>

```json Request Body (JSON)
{
  "Keyword": "test",
  "Types": [
    "contact",
    "company",
    "deal",
    "case",
    "attachment"
  ]
}
```

```shellscript Request Body (cURL)
curl --location --request POST '{{baseURL}}/api/search/search?apikey={{API_KEY}}' \
--header 'Content-Type: application/json' \
--data '{
  "Keyword": "آشنا",
  "Types": [
    "contact",
    "company",
    "deal",
    "case",
    "attachment"
  ]
}'
```

</RequestExample>
