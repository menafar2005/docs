# اتصال n8n به دیدار و ساخت Credential

برای استفاده از نود اختصاصی دیدار در n8n باید ابتدا Credential مربوط به دیدار را ایجاد و API Key حساب دیدار خود را وارد کنید.

## دریافت API Key از دیدار

برای اتصال n8n به دیدار ابتدا باید API Key دریافت کنید.

مراحل دریافت API Key:

1. وارد حساب دیدار شوید.
2. به بخش تنظیمات بروید.
3. وارد بخش API شوید.
4. یک API Key جدید ایجاد کنید.
5. مقدار Key را کپی کنید.

\[محل قرارگیری تصویر: مسیر تنظیمات دیدار برای ایجاد API Key\]

> توجه کنید که مقدار API Key با شناسه API متفاوت است. هنگام اتصال باید مقدار Key را وارد کنید، نه API ID.

## ایجاد Credential در n8n

1. وارد محیط n8n شوید.
2. از منوی سمت چپ وارد بخش Credentials شوید.
3. گزینه Create Credential را انتخاب کنید.
4. نود Didar CRM را انتخاب کنید.

\[محل قرارگیری تصویر: صفحه Credentials و انتخاب Didar CRM\]

5. مقدار API Key دریافت شده از دیدار را در فیلد مربوطه وارد کنید.
6. Credential را ذخیره کنید.

\[محل قرارگیری تصویر: فرم Credential نود دیدار با فیلد API Key\]

## استفاده از Credential در Workflow

بعد از ذخیره Credential:

1. یک نود Didar CRM به Workflow اضافه کنید.
2. در بخش Credential، موردی که ساخته‌اید را انتخاب کنید.
3. عملیات موردنظر را انتخاب کنید.

حالا n8n می‌تواند درخواست‌ها را با حساب دیدار شما ارسال کند.
