# اتصال n8n به دیدار و ساخت Credential

برای استفاده از Node اختصاصی دیدار در n8n، ابتدا باید Credential مربوط به دیدار را ایجاد کنید. این Credential شامل API Key است که برای احراز هویت درخواست‌ها به APIهای دیدار استفاده می‌شود.

## دریافت API Key از دیدار

قبل از ساخت Credential در n8n باید یک API Key از دیدار دریافت کنید.

مراحل دریافت API Key:

1. وارد حساب کاربری دیدار شوید. 
2. به بخش تنظیمات بروید.
3. وارد بخش اتصال به سرور های دیگر شوید.
4. وارد تب اتصال به دیدار شوید
5. دکمه "ایجاد API جدید" بزنید و یک API Key جدید ایجاد کنید. حتما دقت کنید که مقدار API Key را قبل از ذخیره کپی کنید زیرا پس از ایجاد مقدار API Key برای شما قابل مشاهده نخواهد بود

<Note>
  مقدار **API Key** با **API ID** متفاوت است. هنگام اتصال n8n باید مقدار Key را وارد کنید و استفاده از API ID باعث خطای اتصال می‌شود.
</Note>

## ساخت Credential در n8n

مراحل ساخت Credential:

1. وارد پنل n8n شوید.
2. از منوی سمت چپ وارد بخش **Credentials** شوید.

![Screenshot 2026 08 29 180939](/images/Screenshot-2026-08-29-180939.png "Screenshot 2026 08 29 180939")

1. گزینه **Create Credential** را انتخاب کنید.
2. Node مربوط به **Didar CRM** را انتخاب کنید.

\[محل قرارگیری تصویر: صفحه Credentials و انتخاب Didar CRM\]

5. API Key دریافت شده از دیدار را در فیلد مربوطه وارد کنید.
6. Credential را ذخیره کنید.

\[محل قرارگیری تصویر: فرم Credential نود دیدار و فیلد API Key\]

## استفاده از Credential در Workflow

بعد از ذخیره Credential:

1. یک Node دیدار به Workflow اضافه کنید.
2. در قسمت Credential، موردی که ایجاد کرده‌اید را انتخاب کنید.
3. عملیات موردنظر را انتخاب کنید.

حالا درخواست‌های ارسال شده توسط Node دیدار با دسترسی حساب متصل شده اجرا می‌شوند.
