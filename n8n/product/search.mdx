# Product — search

این صفحه ورودی‌های نود n8n و endpoint متناظر دیدار را توضیح می‌دهد.

## Endpoint

```http
POST {{baseURL}}/api/product/search?apikey={{API_KEY}}
```

## فیلدهای نود

| عنوان در n8n | نوع | وضعیت |
| --- | --- | --- |
| Keywords | `string` | اختیاری |
| Limit | `string` | اختیاری |

اطلاعات و پارامترهای این نود بر اساس endpoint بالا تنظیم می‌شوند.
