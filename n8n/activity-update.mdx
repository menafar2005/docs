# Update Activity

نود **Update Activity** برای ویرایش فعالیت موجود در دیدار استفاده می‌شود.

## Endpoint متناظر

این نود بر پایه Endpoint زیر ساخته شده است:

[Update Activity API](/Update-Activity)

## Operation

برای بروزرسانی فعالیت، شناسه فعالیت به همراه مقادیر جدید ارسال می‌شود.

## فیلدهای اصلی

### Id

شناسه فعالیتی که قرار است بروزرسانی شود. این فیلد الزامی است.

### Title

عنوان فعالیت.

### Activity Type

نوع فعالیت با انتخاب از لیست یا ورود دستی شناسه.

### Owner

مسئول فعالیت.

### Is Done

وضعیت انجام شدن فعالیت.

## Additional Fields

فیلدهای تکمیلی قابل بروزرسانی:

- Note
- Result Note
- Tags
- Is Deleted
- Is Pinned
- Due Date
- Duration
- Done Date
- Deal ID
- Case ID
- Contact IDs
- Creator ID
- Recurrence Type
- Recurrence Data
- Recurrence End Date

ساختار این فیلدها مطابق Endpoint ویرایش فعالیت دیدار است.
