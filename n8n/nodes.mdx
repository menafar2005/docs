# نودهای n8n دیدار

نود اختصاصی دیدار مجموعه‌ای از عملیات آماده برای کار با APIهای دیدار را در اختیار شما قرار می‌دهد.

هر نود براساس یکی از APIهای دیدار ساخته شده است و عملکرد آن مطابق همان Endpoint است.

## فعالیت‌ها (Activities)

### Create Activity

ایجاد فعالیت جدید در دیدار.

Endpoint متناظر:

Create Activity

لینک مستندات:

Create-Activity

---

### Update Activity

ویرایش فعالیت موجود در دیدار.

لینک مستندات:

---

### Search Activity

جستجوی فعالیت‌ها در دیدار.

Search Activity
