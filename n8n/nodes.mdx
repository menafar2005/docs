# نودهای n8n دیدار

Node اختصاصی دیدار مجموعه‌ای از عملیات آماده برای کار با APIهای دیدار را در اختیار شما قرار می‌دهد.

هر Operation در Node دیدار معادل یک Endpoint در API دیدار است. بنابراین برای شناخت دقیق ورودی‌ها، خروجی‌ها و نحوه استفاده از هر Operation می‌توانید به مستندات Endpoint مربوطه مراجعه کنید.

## عملیات‌های Node دیدار
