# Search Activity

نود **Search Activity** برای جستجو و دریافت فعالیت‌های موجود در دیدار استفاده می‌شود.

## Endpoint متناظر

این نود بر پایه Endpoint زیر ساخته شده است:

[Search Activity API](/Search-Activity)

## Operation

با استفاده از این نود می‌توانید فعالیت‌ها را بر اساس فیلترهای مختلف جستجو کنید.

## فیلترهای اصلی

### Activity Types

جستجو بر اساس یک یا چند نوع فعالیت.

### Owner

فیلتر فعالیت‌ها بر اساس مسئول فعالیت.

### Contact IDs

فیلتر بر اساس مخاطب‌های مرتبط.

### Deal ID

فیلتر فعالیت‌های مرتبط با یک معامله.

### Case ID

فیلتر فعالیت‌های مرتبط با یک کارت.

### Creator

فیلتر بر اساس ایجادکننده فعالیت.

## Additional Filters

فیلترهای تکمیلی شامل:

- From Date
- To Date
- Is Done
- Is Deleted
- Tag IDs
- From
- Limit

ساختار ورودی‌ها مطابق Endpoint جستجوی فعالیت دیدار است.
