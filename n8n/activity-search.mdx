# Search Activity Node

با این نود می‌توانید فعالیت‌ها را براساس پارامترهای مختلف جستجو کنید.

## Endpoint متناظر

```http
POST {{baseURL}}/api/activity/search?apikey={{API_KEY}}
```

## Filters

### Activity Types

**API Property:** `ActivityTypeIds[]`

لیست شناسه نوع فعالیت برای محدود کردن نتایج.

در n8n می‌توانید از لیست انتخاب کنید یا شناسه‌ها را دستی وارد کنید.

### Owner

**API Property:** `OwnerId`

فیلتر براساس مسئول فعالیت.

### Creator

**API Property:** `CreatorId`

فیلتر براساس ایجادکننده فعالیت.

### Contact IDs

**API Property:** `ContactIds[]`

لیست مخاطبان مرتبط.

### Deal ID

**API Property:** `DealId`

فیلتر براساس معامله مرتبط.

### Case ID

**API Property:** `CaseId`

فیلتر براساس کارت مرتبط.

### Is Done

**API Property:** `IsDone`

فیلتر وضعیت انجام فعالیت:

- `true`
- `false`

### Is Deleted

**API Property:** `IsDeleted`

فیلتر وضعیت حذف.

### Tag IDs

**API Property:** `TagIds[]`

فیلتر براساس تگ‌ها.

## Pagination

- `From`: نقطه شروع نتایج
- `Limit`: تعداد نتایج قابل دریافت

## Date Range

- `FromDate`: ابتدای بازه زمانی
- `ToDate`: انتهای بازه زمانی
