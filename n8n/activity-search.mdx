# Search Activity Node

نود **Search Activity** برای جستجو و دریافت لیست فعالیت‌ها در دیدار استفاده می‌شود.

این نود از API زیر استفاده می‌کند:

```text
POST /api/activity/search
```

## فیلترهای اصلی

### Activity Types

امکان انتخاب چند نوع فعالیت یا ورود شناسه‌ها به صورت دستی وجود دارد.

### Owner

فیلتر بر اساس مسئول فعالیت.

### Creator

فیلتر بر اساس ایجادکننده فعالیت.

### Contact IDs

جستجو بر اساس مخاطبین مرتبط.

### Deal ID

فیلتر فعالیت‌های مرتبط با یک معامله.

### Case ID

فیلتر فعالیت‌های مرتبط با یک کارت.

## Additional Filters

### From Date / To Date

محدوده زمانی جستجو.

### Is Done

فیلتر وضعیت انجام شدن فعالیت.

### Is Deleted

فیلتر وضعیت حذف شدن فعالیت.

### Tag IDs

فیلتر بر اساس تگ‌ها.

### Pagination

- From: مقدار شروع نتایج
- Limit: تعداد نتایج برگشتی

## خروجی

نتایج جستجو به همراه معیارهای ارسال‌شده در خروجی نود قرار می‌گیرد.
