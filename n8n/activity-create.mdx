# Create Activity Node

با این نود می‌توانید یک فعالیت جدید در دیدار ایجاد کنید. این نود بر اساس Endpoint [Create Activity](/Create-Activity) ساخته شده است.

## Endpoint متناظر

```http
POST {{baseURL}}/api/activity/save?apikey={{API_KEY}}
```

## Activity Type

**API Property:** `Activity.ActivityTypeId`

مشخص می‌کند این فعالیت از چه نوعی است؛ مثلا تماس، جلسه یا پیگیری.

در n8n دو روش برای مقداردهی وجود دارد:

- **Select from list:** انتخاب نوع فعالیت از لیست دیدار
- **Enter ID manually:** وارد کردن مستقیم شناسه نوع فعالیت

مقدار واردشده باید `Id` یکی از نوع‌های فعالیت موجود در دیدار باشد.

## Title

**API Property:** `Activity.Title`

عنوان کوتاه فعالیت که به کاربر نمایش داده می‌شود.

این فیلد الزامی است.

## Owner

**API Property:** `Activity.OwnerId`

شناسه User مسئول انجام و پیگیری فعالیت است.

در n8n می‌توانید کاربر را از لیست انتخاب کنید یا UserId را دستی وارد کنید.

## Is Done

**API Property:** `Activity.IsDone`

وضعیت انجام فعالیت را مشخص می‌کند:

- `true` — انجام شده
- `false` — انجام نشده

## Additional Fields

- `Activity.Note`: توضیحات لازم پیش از انجام فعالیت
- `Activity.ResultNote`: نتیجه نهایی فعالیت
- `Activity.Tags[]`: شناسه تگ‌های مرتبط با فعالیت
- `Activity.DealId`: شناسه معامله مرتبط
- `Activity.CaseId`: شناسه کارت مرتبط
- `Activity.ContactIds[]`: شناسه مخاطبان مرتبط
- `Activity.CreatorId`: شناسه ایجادکننده فعالیت
- `Activity.RecurrenceType`: الگوی تکرار فعالیت
- `Activity.RecurrenceData`: فاصله تکرار
- `Activity.RecurrenceEndDate`: تاریخ پایان تکرار
