# Create Activity Node

نود **Create Activity** برای ایجاد فعالیت جدید در دیدار استفاده می‌شود. این نود از API زیر استفاده می‌کند:

```text
POST /api/activity/save
```

## فیلدهای اصلی

### Title

عنوان فعالیت. این فیلد الزامی است.

### Activity Type

نوع فعالیت را می‌توان به دو روش مشخص کرد:

- انتخاب از لیست Activity Type های موجود
- وارد کردن شناسه Activity Type به صورت دستی

### Owner

مسئول فعالیت را می‌توان به دو روش مشخص کرد:

- انتخاب کاربر از لیست کاربران
- وارد کردن شناسه کاربر به صورت دستی

### Is Done

مشخص می‌کند فعالیت انجام شده است یا خیر.

## Additional Fields

### Note

یادداشت فعالیت.

### Result Note

نتیجه فعالیت.

### Tags

شناسه تگ‌های مرتبط با نتیجه فعالیت. این مقدار فقط در صورت ارسال Result Note ارسال می‌شود.

### Due Date

تاریخ سررسید فعالیت.

### Duration

مدت زمان فعالیت.

### Done Date

تاریخ انجام فعالیت.

### Deal ID

شناسه معامله مرتبط با فعالیت.

### Case ID

شناسه کارت مرتبط با فعالیت.

### Contact IDs

شناسه مخاطبین مرتبط با فعالیت.

### Creator ID

شناسه ایجادکننده فعالیت.

### Recurrence

برای تنظیم فعالیت‌های تکرارشونده استفاده می‌شود و شامل نوع تکرار، داده تکرار و تاریخ پایان تکرار است.

## خروجی

پاسخ API ایجاد فعالیت در خروجی نود برگردانده می‌شود.
