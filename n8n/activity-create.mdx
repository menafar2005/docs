# Create Activity

نود **Create Activity** برای ایجاد فعالیت جدید در دیدار استفاده می‌شود.

## Endpoint متناظر

این نود بر پایه Endpoint زیر ساخته شده است:

[Create Activity API](/Create-Activity)

## Operation

این نود درخواست ایجاد فعالیت را به Endpoint ذخیره فعالیت ارسال می‌کند.

## فیلدهای اصلی

### Title

عنوان فعالیت. این فیلد الزامی است.

### Activity Type

نوع فعالیت را مشخص می‌کند. می‌توانید:

- نوع فعالیت را از لیست انتخاب کنید.
- شناسه نوع فعالیت را به صورت دستی وارد کنید.

### Owner

مسئول فعالیت را مشخص می‌کند. می‌توانید کاربر را از لیست انتخاب کنید یا شناسه آن را وارد کنید.

### Is Done

مشخص می‌کند فعالیت انجام شده است یا خیر.

## Additional Fields

فیلدهای تکمیلی فعالیت شامل:

- Note
- Result Note
- Tags
- Is Deleted
- Is Pinned
- Due Date
- Duration
- Done Date
- Deal ID
- Case ID
- Contact IDs
- Creator ID
- Recurrence Type
- Recurrence Data
- Recurrence End Date

ساختار و مقادیر این فیلدها مطابق Endpoint اصلی دیدار است.
