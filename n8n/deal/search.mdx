# Deal — search

این صفحه ورودی‌های نود n8n و endpoint متناظر دیدار را توضیح می‌دهد.

## Endpoint

```http
POST {{baseURL}}/api/deal/search_v2?apikey={{API_KEY}}
```

| عنوان در n8n | نوع | وضعیت |

| Owner Input Mode | `options` | اختیاری |
