# Person — get

این صفحه تنظیمات و ورودی‌های نود n8n دیدار را برای endpoint متناظر توضیح می‌دهد. نام فیلدها، وضعیت الزامی و حالت‌های انتخابی مطابق همین نود است.

## Endpoint

```http
POST {{baseURL}}/api/contact/GetContactDetail?apikey={{API_KEY}}
```

## نگاشت endpoint

فیلدهای بالای نود به پارامترهای endpoint با همان نام‌های API ارسال می‌شوند. فیلدهایی که در نود به‌صورت **Select from list** و **Enter ID manually** ارائه شده‌اند، دو روش ورود همان شناسه endpoint هستند؛ در حالت انتخاب از فهرست، مقدار انتخاب‌شده و در حالت دستی، مقدار واردشده ارسال می‌شود.

مستندات endpoint متناظر: [Get-Person-By-Id](/Get-Person-By-Id).
