# Person — update

## Endpoint

```http
POST {{baseURL}}/api/contact/save?apikey={{API_KEY}}
```

## فیلدهای نود

فیلدهای این نود برای ارسال اطلاعات ویرایش شخص به endpoint بالا استفاده می‌شوند: `Id`، `FirstName`، `LastName`، `MobilePhone`، `WorkPhone`، `OwnerId` و فیلدهای اضافی endpoint.
