# شروع کار با n8n

n8n یک ابزار اتوماسیون است که امکان اتصال سرویس‌های مختلف و ساخت Workflowهای خودکار را فراهم می‌کند. برای اتصال n8n به دیدار دو روش اصلی وجود دارد.

## تفاوت نسخه Cloud و Self-hosted در n8n

### نسخه Cloud (ابری)

نسخه Cloud همان نسخه‌ای است که از طریق سایت رسمی n8n در آدرس n8n.io استفاده می‌کنید. در این مدل، n8n روی سرورهای n8n اجرا می‌شود و برای استفاده از آن باید اشتراک تهیه کنید.

در نسخه Cloud امکان نصب پکیج‌های اختصاصی مثل نود دیدار وجود ندارد. برای اتصال به دیدار باید از نودهای عمومی n8n استفاده کنید:

- نود HTTP Request برای ارسال درخواست به APIهای دیدار
- نود Webhook برای دریافت وبهوک‌های دیدار

\[محل قرارگیری تصویر: صفحه ساخت Workflow در نسخه Cloud n8n و نمایش نودهای HTTP Request و Webhook\]

### نسخه Self-hosted (نصب روی سرور شخصی)

در نسخه Self-hosted، کد باز n8n را دریافت کرده و آن را روی سرور خودتان اجرا می‌کنید. این سرور می‌تواند سرور سازمان، VPS یا هر محیط دیگری باشد که خودتان مدیریت می‌کنید.

در این نسخه امکان نصب نود اختصاصی دیدار وجود دارد. نود اختصاصی دیدار براساس APIهای دیدار توسعه داده شده و امکان استفاده مستقیم از قابلیت‌های دیدار را داخل Workflowهای n8n فراهم می‌کند.

## نصب نود اختصاصی دیدار در نسخه Self-hosted

نام پکیج نود دیدار در npm:

```text
n8n-nodes-didar-crm
```

صفحه npm نود:

[https://www.npmjs.com/package/n8n-nodes-didar-crm](https://www.npmjs.com/package/n8n-nodes-didar-crm)

### مراحل نصب

1. وارد سروری شوید که n8n روی آن نصب شده است.
2. دستور زیر را برای نصب نود اجرا کنید:

```bash
npm install n8n-nodes-didar-crm
```

3. بعد از نصب، سرویس n8n را ری‌استارت کنید.

\[محل قرارگیری تصویر: ترمینال سرور بعد از اجرای دستور نصب موفق\]

4. وارد محیط n8n شوید.
5. در زمان ساخت Workflow، در لیست Nodeها عبارت Didar را جستجو کنید.

\[محل قرارگیری تصویر: جستجوی نود Didar در پنل نودهای n8n\]

6. نود دیدار را انتخاب کرده و در Workflow خود استفاده کنید.

## قدم بعدی

بعد از نصب نود، برای اتصال آن به حساب دیدار باید Credential مربوط به دیدار را ایجاد کنید.

در صفحه بعد نحوه ساخت Credential و وارد کردن API Key توضیح داده شده است.
