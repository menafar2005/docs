# دریافت نوع فعالیت

فعالیت‌های هر کسب‌وکار می‌توانند انواع مختلفی مثل تماس، جلسه یا پیگیری داشته باشند.‎ این Endpoint فهرست انواع فعالیت موجود در بیزدامنه را برمی‌گرداند تا ID نوع موردنظر را پیدا کرده و هنگام ایجاد یا جستجوی فعالیت استفاده کنید.‎

```http
POST {{baseURL}}/api/activity/GetActivityType?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## بدنه درخواست

> این درخواست بدنه ندارد.

## قواعد و محدودیت‌ها

- مقدار `ID` هر نوع فعالیت را میتوانید در فیلد `ActivityTypeId` ایجاد فعالیت جدید استفاده کنید
