# فهرست کاریز معاملات

هر معامله داخل یکی از مراحل کاریز فروش قرار می‌گیرد.‎ این Endpoint فهرست کاریزهای معامله و مراحل هرکدام را برمی‌گرداند تا ID کاریز و مرحله موردنظر را برای ایجاد، ویرایش یا جستجوی معاملات استفاده کنید.‎

```http
POST {{baseURL}}/api/pipeline/list/0?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## بدنه درخواست

> این درخواست بدنه ندارد.

## قواعد و محدودیت‌ها

- لیستی از پارامتر کاریز معاملات را میدهد
- مقدار `Response[].Id` برابر است با شناسه کاریز معامله
- مقدار `Response[].Stages[].Id` برابر است با شناسه مرحله یک کاریز مشخص معامله
