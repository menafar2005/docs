# فهرست کاریز کارت ها

کارت‌ها از کاریزهای جداگانه‌ای نسبت به معاملات استفاده می‌کنند.‎ این Endpoint فهرست کاریزهای کارت و مراحل هرکدام را برمی‌گرداند تا شناسه مرحله مناسب را هنگام ایجاد، ویرایش یا جستجوی کارت‌ها استفاده کنید.‎

```http
POST {{baseURL}}/api/pipeline/list/1?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## بدنه درخواست

> این درخواست بدنه ندارد.

## قواعد و محدودیت‌ها

- لیستی از پارامتر کاریز کارت ها را میدهد
- مقدار `Response[].Id` برابر است با شناسه کاریز کارت
- مقدار `Response[].Stages[].Id` برابر است با شناسه مرحله یک کاریز مشخص کارت
