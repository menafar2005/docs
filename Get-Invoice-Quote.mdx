# دریافت فاکتور یا پیش‌فاکتور

این Endpoint برای دریافت اطلاعات یک فاکتور یا پیش‌فاکتور مشخص استفاده می‌شود. برای پیدا کردن سند می‌توانید یکی از شناسه، شماره سند یا شماره فرمت‌شده آن را ارسال کنید.

**در هر درخواست باید فقط و فقط یکی از فیلدهای `Id`، `InvoiceFormattedNumber`، `InvoiceNumber`، `QuoteFormattedNumber` یا `QuoteNumber` ارسال شود. ارسال همزمان دو یا چند مورد باعث خطا می‌شود.**

```http
POST {{baseURL}}/api/AccountingInvoice/Get?apikey={{API_KEY}}
```

## پارامترهای Query

| پارامتر | نوع | وضعیت | توضیح |
| --- | --- | --- | --- |
| `apikey` | `string` | الزامی | کلید API دیدار. |

## Header درخواست

```text
Content-Type: application/json
```

## بدنه درخواست

بدنه درخواست باید **دقیقاً یکی** از فیلدهای زیر را داشته باشد.

<ParamField path="Id" type="number">
  شناسه فاکتور یا پیش‌فاکتوری است که می‌خواهید دریافت کنید. همین فیلد برای شناسه هر دو نوع سند، یعنی فاکتور و پیش‌فاکتور، استفاده می‌شود.

  <Expandable title="شرایط ارسال">
    اگر `Id` را ارسال می‌کنید، هیچ‌کدام از فیلدهای `InvoiceFormattedNumber`، `InvoiceNumber`، `QuoteFormattedNumber` یا `QuoteNumber` را همراه آن نفرستید.
  </Expandable>
</ParamField>

<ParamField path="InvoiceFormattedNumber" type="string">
  شماره فرمت‌شده فاکتور است؛ برای مثال `I-23`.

  <Expandable title="شرایط ارسال">
    اگر `InvoiceFormattedNumber` را ارسال می‌کنید، هیچ‌کدام از چهار فیلد دیگر را همراه آن نفرستید.
  </Expandable>
</ParamField>

<ParamField path="InvoiceNumber" type="string">
  شماره فاکتور است؛ برای مثال `23.0`.

  <Expandable title="شرایط ارسال">
    اگر `InvoiceNumber` را ارسال می‌کنید، هیچ‌کدام از چهار فیلد دیگر را همراه آن نفرستید.
  </Expandable>
</ParamField>

<ParamField path="QuoteFormattedNumber" type="string">
  شماره فرمت‌شده پیش‌فاکتور است؛ برای مثال `Q-21`.

  <Expandable title="شرایط ارسال">
    اگر `QuoteFormattedNumber` را ارسال می‌کنید، هیچ‌کدام از چهار فیلد دیگر را همراه آن نفرستید.
  </Expandable>
</ParamField>

<ParamField path="QuoteNumber" type="string">
  شماره پیش‌فاکتور است؛ برای مثال `21.0`.

  <Expandable title="شرایط ارسال">
    اگر `QuoteNumber` را ارسال می‌کنید، هیچ‌کدام از چهار فیلد دیگر را همراه آن نفرستید.
  </Expandable>
</ParamField>

## قواعد و محدودیت‌ها

- بدنه درخواست باید **دقیقاً یک** فیلد از بین `Id`، `InvoiceFormattedNumber`، `InvoiceNumber`، `QuoteFormattedNumber` و `QuoteNumber` داشته باشد.
- ارسال دو یا چند فیلد از این مجموعه در یک درخواست معتبر نیست و Endpoint خطا برمی‌گرداند.
- فیلد `Id` هم برای شناسه فاکتور و هم برای شناسه پیش‌فاکتور استفاده می‌شود؛ فیلد جداگانه‌ای مثل `InvoiceId` یا `QuoteId` در این درخواست ارسال نمی‌شود.
- برای دریافت فاکتور با شماره فرمت‌شده از `InvoiceFormattedNumber` و برای دریافت پیش‌فاکتور با شماره فرمت‌شده از `QuoteFormattedNumber` استفاده کنید.
- برای دریافت فاکتور با شماره سند از `InvoiceNumber` و برای دریافت پیش‌فاکتور با شماره سند از `QuoteNumber` استفاده کنید.

### نمونه درخواست‌های معتبر

با شناسه فاکتور یا پیش‌فاکتور:

```json
{
  "Id": 2220689
}
```

با شماره فرمت‌شده فاکتور:

```json
{
  "InvoiceFormattedNumber": "I-23"
}
```

با شماره فاکتور:

```json
{
  "InvoiceNumber": "23.0"
}
```

با شماره فرمت‌شده پیش‌فاکتور:

```json
{
  "QuoteFormattedNumber": "Q-21"
}
```

با شماره پیش‌فاکتور:

```json
{
  "QuoteNumber": "21.0"
}
```

### نمونه درخواست نامعتبر

در درخواست زیر دو فیلد برای پیدا کردن سند همزمان ارسال شده‌اند؛ بنابراین این درخواست نامعتبر است و خطا برمی‌گرداند.

```json
{
  "Id": 2220689,
  "InvoiceFormattedNumber": "I-23"
}
```

  "Id": 2220689
}

```shellscript Request Body (cURL)
curl --location '{{baseURL}}/api/AccountingInvoice/Get?apikey={{API_KEY}}' \
--header 'Content-Type: application/json' \
--data '{
  "Id": 2220689
}'
```
